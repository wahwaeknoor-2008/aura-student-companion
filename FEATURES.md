# AURA — Features and MVP Scope

## MVP priorities
1. Account/onboarding foundation (authentication to be added after initial scaffold).
2. Student dashboard.
3. Tasks and daily checklist.
4. Basic habit tracking.
5. Courses and academic deadlines.
6. AI conversation interface and backend integration, after privacy/provider decisions.

## Version 1 feature details
### Dashboard
- Personalized greeting
- Tasks due today
- Upcoming academic deadlines
- Habit progress
- Quick access to companion

### Academic planner
- Courses
- Assignments, quizzes, midterms, and exams
- Due dates and study tasks
- Completion status

### Habits
- Hydration, meals, sleep, exercise, and custom habits
- Flexible goals and rest days
- Progress summaries without shame-based messaging

### AI companion
- Text conversation
- Clear disclosure of cloud processing
- Student-controlled conversation history and memory

## Later phases
- Voice conversations
- Optional camera-based guidance
- Smart reminders
- Calendar/LMS integrations
- Local AI and offline capabilities

## MVP success criteria
A student can open the app, understand the dashboard, create and complete a task, and navigate the core sections. Backend persistence and AI features will be added incrementally.
